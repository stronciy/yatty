# yatty: дизайн терминала для macOS

Дата: 2026-11-08
Статус: утверждён пользователем

## 1. Цель

Лёгкий, быстрый терминал для macOS (Apple Silicon) на Rust, который подходит для ежедневной работы. Ключевые требования:

- современный минималистичный стиль окна и табов, прямоугольные элементы без скруглений;
- гибкая конфигурация через TOML с горячей перезагрузкой;
- производительность и отзывчивость;
- публичный продукт: подпись, нотаризация, распространение через Homebrew.

## 2. Объём MVP

Входит:
- табы, сплиты (панели), профили;
- ligatures и Nerd Fonts;
- true color и поддержка мыши;
- горячая перезагрузка конфига;
- поиск по выводу (scrollback);
- стандартные горячие клавиши macOS;
- новые табы и панели открываются в текущей папке.

Не входит: Linux и Windows, встроенный AI, блоки команд, плагины, GUI-редактор настроек, синхронизация конфига.

## 3. Архитектура

Cargo workspace из пяти крейтов. Зависимости направлены сверху вниз, циклов нет.

```
app  ──►  ui  ──►  render
 │         │        │
 │         ▼        ▼
 │      term  ◄──  config
 │    (PTY + alacritty_terminal)
 ▼
(сборка, окно, macOS-интеграция)
```

| Крейт | Назначение | Не делает |
|---|---|---|
| `term` | PTY, запуск шелла, `alacritty_terminal`, трекинг CWD (OSC 7), сессии | Не знает про окна и отрисовку |
| `render` | wgpu, атлас глифов, шейпинг (ligatures), fallback шрифтов | Не знает про табы и сплиты |
| `ui` | Дерево табов и сплитов, фокус, поиск, панель табов, хоткеи | Не работает с PTY напрямую |
| `config` | TOML, схема, профили, file watcher | Не содержит логики UI |
| `app` | Точка входа, окно (winit), цикл событий, сборка `.app`, подпись | Не содержит бизнес-логики |

Границы:
- `term` отдаёт `ui` сетку символов для каждой панели. `render` получает только данные для отрисовки, а не живые объекты терминала.
- `config` публикует изменения через канал. `ui` и `render` подписываются на них.
- Каждый терминальный экземпляр изолирован за интерфейсом `Session`, поэтому табы и сплиты тестируются без реального шелла.

### Milestones

- **M0. Спайк рендера:** одно окно, wgpu, один шелл, ввод и вывод, моноширинный шрифт. Проверка производительности и шейпинга.
- **M1. Один терминал полностью:** true color, мышь, ligatures, Nerd Fonts, конфиг TOML.
- **M2. Табы:** панель сверху, создание, закрытие, переключение, переименование, наследование CWD.
- **M3. Сплиты и профили:** дерево панелей, фокус, профили со шрифтом, темой, шеллом и env.
- **M4. Поиск, горячая перезагрузка, полировка.**
- **M5. Релиз:** подпись, нотаризация, `.dmg`, Homebrew.

## 4. Визуальный стиль

Общие принципы:
- Радиус всех элементов 0. Без теней и градиентов. Обводки 1 px.
- Тёмная палитра с приглушёнными цветами, один акцентный цвет.
- Разделители 1 px, отступы на сетке 4 px, контраст текста не ниже WCAG AA.

Панель табов (отдельная полоса сверху):
- Высота около 32 px, фон чуть темнее области терминала.
- Активный таб: фон чуть светлее и акцентная линия 2 px (сверху или снизу, настраивается).
- Неактивные табы без линии, приглушённый текст.
- Разделитель 1 px между табами. Крестик закрытия появляется при наведении или на активном табе (настраивается).
- Название таба: текущая папка или запущенная программа. Можно переименовать вручную.
- Индикатор активности: точка акцентного цвета на табе с новым выводом, пока он не в фокусе.
- Ширина адаптивная, с минимумом и обрезкой многоточием. Кнопка «+» справа.

Сплиты: разделитель 1 px. Активная панель имеет тонкую акцентную рамку 1 px.

Палитра по умолчанию (уточним на M1): фон `#1A1B1F`, полоса табов `#15161A`, активный таб `#24262C`, акцент `#7AA2F7`, текст `#C0C5D0`, приглушённый текст `#6B7180`.

Весь стиль задаётся в TOML без пересборки.

## 5. Конфигурация и профили

Файл: `~/.config/yatty/config.toml`. Горячая перезагрузка через file watcher. При ошибке в файле применяется последняя рабочая конфигурация, и показывается уведомление.

Пример:

```toml
[window]
tab_bar_height = 32
tab_indicator = "top"        # "top" | "bottom"
close_button = "hover"       # "always" | "hover" | "never"

[font]
family = "JetBrains Mono Nerd Font"
size = 13.0
ligatures = true

[colors]
background = "#1A1B1F"
accent = "#7AA2F7"

[profile.default]
shell = "/bin/zsh"
args = ["-l"]
cwd = "inherit"              # "inherit" | "home" | путь
env = { EDITOR = "nvim" }

[profile.ssh-prod]
shell = "/usr/bin/ssh"
args = ["prod-server"]
colors = { background = "#2A1515" }

[general]
default_profile = "default"
startup_profile = "default"  # или "ask"
```

Правила:
- Профиль наследует `[font]`, `[colors]` и `[window]` и переопределяет свои поля.
- `cwd = "inherit"` открывает новую вкладку или панель в текущей папке.
- Выбор профиля при запуске через `startup_profile` или меню «Новая вкладка → профиль» по отдельной клавише.
- Неизвестные ключи дают предупреждение. Невалидные значения откатываются к значениям по умолчанию с сообщением в строке статуса.

## 6. Ошибки и надёжность

- Завершение шелла: таб показывает статус с кодом выхода и предлагает перезапуск. Остальные табы не затрагиваются.
- Ошибка инициализации wgpu или шрифта: понятное сообщение, без тихого падения. Для отсутствующего глифа используется fallback.
- Ошибки PTY логируются в `~/Library/Logs/yatty/`, пользователю показываются только если мешают работе.

## 7. Тестирование

- `config`: модульные тесты на парсинг, наследование профилей и откат при ошибке.
- `ui`: тесты дерева табов и сплитов (создание, закрытие, фокус, перемещение) через `Session`-интерфейс без шелла.
- `term`: интеграционные тесты с настоящим PTY: запуск команды, вывод, CWD через OSC 7.
- `render`: снимки отрисовки эталонной сетки символов для контроля регрессий шрифтов и ligatures.
- Ручной чек-лист на каждом milestone: ввод, вставка, мышь, true color, Nerd Fonts, горячая перезагрузка.

## 8. Производительность (цели)

- Холодный старт до первого кадра: менее 200 мс.
- Ввод → отрисовка: менее 16 мс на кадр (60 FPS).
- Память в простое: менее 100 МБ на вкладку (ориентир, уточним на M0).
- Большой вывод (например, `cat` большого файла) не блокирует интерфейс.

## 9. Риски и открытые вопросы

- Шейпинг ligatures в wgpu: проверяем первым на M0.
- Производительность атласа глифов при большом выводе: проверяем на M0.
- Стабильность API `alacritty_terminal`: фиксируем версию и обновляем осознанно.
- Точные значения палитры и поведения табов уточняются на M1 и M2.
