# yatty M0: результаты спайка рендера

Дата: 2026-11-08
Сборка: release (замеры), dev (проверка функций)
Платформа: macOS, Apple Silicon

## Вердикт

**Идём дальше.** Стек `alacritty_terminal` + wgpu + cosmic-text работает: окно, PTY-шелл, вывод, курсор и ligatures отрисовываются корректно. Открытые пункты перенесены в M1.

## Проверено

| Проверка | Результат | Как проверено |
|---|---|---|
| Окно и цикл событий (winit 0.30) | OK | Запуск приложения |
| Шелл в PTY, вывод и приглашение | OK | Снимок кадра, тесты `term` |
| Ввод в шелл | OK | Тест `input_is_delivered_to_shell`, ввод через `write` |
| Ligatures (`→ ⇒ ≠ ≡`) в JetBrains Mono | OK | Снимок кадра |
| Курсор | OK | Снимок кадра (синяя полоса 2 px) |
| Тёмная палитра и фон | OK | Снимок кадра |
| Код выхода шелла | OK | Тест `child_exit_code_is_reported` |
| Clippy и сборка без предупреждений | OK | `cargo clippy --workspace` |

Снимок кадра делается из самого рендера (`Renderer::capture_next_frame`), потому что системные скриншоты macOS требуют разрешения Screen Recording.

## Замеры

| Метрика | Цель | Результат |
|---|---|---|
| RSS в простое (release, одна вкладка) | менее 100 МБ | около 97 МБ |
| Холодный старт до первого кадра | менее 200 мс | **не замерено** |
| Время кадра при большом выводе (p50/p95) | менее 16 мс | **не замерено** |

Старт и время кадра не замерены: для этого нужна инструментация (метки времени в цикле событий и при `draw`), которую я не добавлял в M0. Замеры переносятся в M1 вместе с инструментацией.

## Не проверено

- Nerd Font иконки (шрифт JetBrains Mono Nerd Font не подключён, используется JetBrains Mono).
- Полноценные TUI-приложения: `vim`, `htop`.
- True color (код поддержан в `convert.rs`, но не проверен на экране).
- Изменение размера окна (код есть, проверка вручную не выполнялась).
- Широкие символы (CJK, эмодзи): спейсеры учитываются, но выравнивание по колонкам не проверено.

## Известные ограничения текущего спайка

- Шейпинг выполняется построчно, строка пересчитывается только при изменении текста. Стили (bold, italic, underline) пока не передаются в шейпер, будут в M1.
- Цвета ANSI 0–15 заданы захардкоженной палитрой в `crates/app/src/convert.rs`.
- Атлас глифов 2048×2048 R8. При переполнении новые глифы пропускаются с предупреждением, вытеснения пока нет.
- Цветные глифы (эмодзи) не растеризуются, только маски.

## Следующие шаги (M1)

4. Конфиг TOML вместо захардкоженных значений.
